## 安装说明

### 系统要求
- macOS 10.12 或更高版本
- Python 3.6 或更高版本

### 安装步骤

1. **检查Python版本**
   ```bash
   python3 --version
   ```
   如果没有安装Python 3，请从 [python.org](https://www.python.org/downloads/) 下载安装。

2. **安装依赖库**
   ```bash
   cd /Users/你的用户名/Programming/拼音标注工具
   pip3 install -r requirements.txt
   ```

3. **运行程序**
   ```bash
   python3 pinyin_tool.py
   ```

## 基本使用

### 启动应用
双击 `pinyin_tool.py` 文件或在终端中运行：
```bash
python3 pinyin_tool.py
```

### 界面说明

1. **输入区域**: 在上方文本框中输入需要转换的中文文本
2. **拼音风格选择**: 选择你需要的拼音输出格式
3. **控制按钮**:
   - **生成拼音**: 转换输入的中文为拼音
   - **复制结果**: 将生成的拼音复制到剪贴板
   - **清空内容**: 清除所有输入和输出内容
4. **结果区域**: 显示转换后的拼音结果
5. **状态栏**: 显示当前操作状态和统计信息

### 快捷键
- `Cmd + Enter`: 快速转换拼音

## 拼音风格说明

### 1. 标准声调 (TONE)
- **格式**: zhōng guó
- **说明**: 使用声调符号标注，最接近标准拼音教学格式
- **适用场景**: 教学、正式文档、儿童读物

### 2. 数字声调 (TONE3)
- **格式**: zhong1 guo2
- **说明**: 用数字1-4表示四个声调，轻声不标注
- **适用场景**: 输入法设置、程序处理、数据存储

### 3. 无声调 (NORMAL)
- **格式**: zhong guo
- **说明**: 纯字母，不包含任何声调信息
- **适用场景**: 搜索索引、简化显示、URL友好格式

### 4. 首字母 (FIRST_LETTER)
- **格式**: z g
- **说明**: 只显示拼音的首字母
- **适用场景**: 快速索引、缩写显示

## 快捷键设置

### 方法一：系统快捷键 (推荐)

1. **打开脚本编辑器**
   - 在应用程序 > 实用工具中找到"脚本编辑器"

2. **导入脚本**
   - 打开 `scripts/quick_pinyin.scpt` 文件
   - 点击"编译"按钮确保脚本正常

3. **保存为应用程序**
   - 文件 > 导出
   - 文件格式选择"应用程序"
   - 保存到应用程序文件夹

4. **设置快捷键**
   - 打开系统偏好设置 > 键盘 > 快捷键
   - 选择"服务"
   - 找到你保存的脚本应用
   - 设置快捷键（建议：`Cmd + Shift + P`）

### 方法二：Automator服务

1. **打开Automator**
   - 选择"服务"模板

2. **配置服务**
   - "服务收到选定的"：文本
   - "位于"：任何应用程序

3. **添加AppleScript动作**
   - 拖入"运行AppleScript"动作
   - 复制 `scripts/quick_pinyin.scpt` 的内容

4. **保存并设置快捷键**
   - 保存服务（如"快速拼音转换"）
   - 在系统偏好设置中设置快捷键

## 双拼用户指南

### 为什么适合双拼用户？

1. **输入效率**: 双拼用户习惯快速输入，本工具提供快捷键支持
2. **拼音熟悉度**: 双拼用户对拼音结构理解深入，能更好利用不同拼音风格
3. **工作流集成**: 可以无缝集成到现有的文字处理工作流中

### 推荐使用方式

1. **日常使用**: 使用快捷键 `Cmd + Shift + P` 快速转换选中文本
2. **批量处理**: 打开GUI应用进行大段文本的拼音标注
3. **格式选择**: 
   - 教学用途：选择"标准声调"
   - 技术文档：选择"数字声调"
   - 快速浏览：选择"首字母"

### 搜狗双拼键位对照

本工具生成的拼音可以帮助你：
- 验证双拼输入是否正确
- 学习生僻字的正确读音
- 为文档添加拼音注释

## 常见问题

### Q: 程序无法启动，提示找不到模块
**A**: 请确保已安装所需依赖：
```bash
pip3 install pypinyin pyperclip
```

### Q: 复制功能不工作
**A**: 这通常是pyperclip库的问题，请尝试：
```bash
pip3 install --upgrade pyperclip
```

### Q: AppleScript快捷键不工作
**A**: 请检查：
1. 脚本路径是否正确
2. 是否给予了必要的系统权限
3. Python3是否在系统PATH中

### Q: 某些字的拼音不准确
**A**: pypinyin库基于词典，对于多音字可能需要上下文判断。你可以：
1. 分词后再转换
2. 手动调整结果
3. 使用自定义词典功能

### Q: 如何处理繁体中文？
**A**: pypinyin库支持繁体中文，直接输入即可转换。
